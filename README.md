# Gửi em yêu ❤

Trang web tặng vợ: bầu trời sao, trái tim hạt quanh ảnh, bộ đếm ngày bên nhau, lá thư, ảnh kỷ niệm, thẻ "lý do anh yêu em" và một câu hỏi bất ngờ ở cuối.

## Tuỳ chỉnh

Mọi nội dung nằm trong [js/config.js](js/config.js):

- `startDate` — ngày bắt đầu yêu nhau / ngày cưới (`NĂM-THÁNG-NGÀY`)
- `letter`, `letterSign` — lá thư
- `photos` — thêm ảnh vào thư mục dự án rồi khai báo ở đây
- `reasons`, `question`, `answer` — các thẻ lý do và câu hỏi cuối
- `music` — file nhạc nền

## Xem thử

```bash
python3 -m http.server 8000
```

Mở http://localhost:8000 (nên xem trên điện thoại).
